# Tailya

**Тема в стиле glassmorphism для GNOME Shell.**

Полупрозрачные панели, мягкие тени, скруглённые дни календаря и один приглушённый фиолетовый акцент.

Всплывающие меню, быстрые настройки и календарь получают полупрозрачную тёмную подложку с мягкой тенью. Дни календаря превращаются в скруглённые «пилюли». У уведомлений аккуратные скругления 16 px. Быстрые переключатели, ползунки и тумблеры используют один приглушённый фиолетовый акцент. Прозрачность текста подобрана так, чтобы он оставался читаемым на любых обоях, а интерактивные элементы плавно меняют состояние за 150 мс.

> **Tailya — это тема GNOME Shell, а не полноценная GTK-тема.** Она оформляет интерфейс оболочки — меню, календарь, уведомления и быстрые настройки — и не затрагивает приложения. Панели и меню тёмные, светлого варианта нет.

## Что меняется

- **Стеклянные поверхности** — всплывающие меню, быстрые настройки и календарь получают полупрозрачный тёмный фон с мягкой тенью.
- **Dash и обзор** — у кнопок Dash и плиток обзора убраны подложки, а сам Dash остаётся лёгкой стеклянной панелью.
- **Календарь** — дни при наведении и текущий день становятся скруглёнными «пилюлями»; подписи и стрелки навигации приведены к одному читаемому стилю.
- **Уведомления** — скругления 16 px, мягкая тень и аккуратно подобранная прозрачность текста.
- **Фиолетовый акцент** — включённые быстрые переключатели, уровни ползунков и тумблеры используют один приглушённый фиолетовый (`rgb(117, 84, 209)`).
- **Читаемый текст** — основной, вторичный и неактивный текст имеют разную прозрачность белого.
- **Плавные переходы** — 150 мс при наведении, фокусе и нажатии.

Тема состоит только из CSS: никаких расширений, скриптов и зависимостей, кроме User Themes.

## Требования

| Что нужно | Детали |
| --- | --- |
| GNOME Shell | 45 или новее (проверено на 45 и 46) |
| User Themes | [расширение](https://extensions.gnome.org/extension/19/user-themes/), включено |
| GNOME Tweaks | необязательно, но так проще всего выбрать тему Shell |

## Установка

### Из архива

```bash
mkdir -p ~/.themes
tar -xf tailya.tar.gz -C ~/.themes
```

Если имя скачанного файла другое, замените `tailya.tar.gz`.

### Из папки проекта

Если вы скачали папку, скопируйте её в каталог тем:

```bash
mkdir -p ~/.themes
cp -r /путь/к/Tailya ~/.themes/
```

Замените `/путь/к/Tailya` на фактический путь.

В итоге должно получиться так:

```text
~/.themes/Tailya/
└── gnome-shell/
    └── gnome-shell.css
```

GNOME также ищет темы в `~/.local/share/themes/` — можно использовать любой из двух каталогов.

### Включение и применение

1. Установите и включите расширение **User Themes**.
2. Откройте **GNOME Tweaks → Внешний вид** (в некоторых дистрибутивах — **Настройки → Внешний вид**) и выберите **Tailya** в списке тем оболочки.
3. Если тема не применилась сразу:
   - **X11:** нажмите `Alt+F2`, введите `r` и нажмите `Enter`.
   - **Wayland:** выйдите из сессии и войдите снова.

Если GNOME Tweaks не установлен, поставьте его из пакетного менеджера вашего дистрибутива.

### Для всех пользователей

```bash
sudo tar -xf tailya.tar.gz -C /usr/share/themes
```

Тема станет доступна всем пользователям системы. Чтобы её выбрать, User Themes всё равно понадобится. Если устанавливаете не архив, а папку, используйте `sudo cp -r /путь/к/Tailya /usr/share/themes/`.

## Удаление

Сначала переключитесь на другую тему Shell, затем удалите папку:

```bash
rm -rf ~/.themes/Tailya
```

Для системной установки:

```bash
sudo rm -rf /usr/share/themes/Tailya
```

## Настройка

Все стили лежат в [`gnome-shell/gnome-shell.css`](gnome-shell/gnome-shell.css).

**Акцентный цвет.** Фиолетовый акцент встречается в трёх оттенках. Чтобы он оставался цельным, замените все три:

```css
rgb(117, 84, 209)  /* обычное состояние */
rgb(135, 105, 222) /* наведение         */
rgb(100, 70, 190)  /* нажатие           */
```

**Прозрачность панелей.** Стеклянные поверхности используют `rgba(30, 30, 30, 0.5)`. Уменьшите альфу для большей прозрачности, увеличьте — для более плотной подложки.

**Уведомления.** Их фон задаётся как `rgb(35, 35, 35)`.

**Скругления.** У уведомлений — `16px`, у «пилюль» календаря и круглых кнопок — `99px`.

После правок перезагрузите оболочку: `Alt+F2` → `r` на X11 или выйдите из сессии и войдите снова на Wayland.

## Решение проблем

**Tailya нет в списке тем Shell.**
Проверьте, что путь ровно такой: `~/.themes/Tailya/gnome-shell/gnome-shell.css`. Перезапустите GNOME Tweaks и убедитесь, что User Themes включено.

**Тема выбрана, но ничего не меняется.**
На Wayland темы Shell применяются при входе в сессию — выйдите и войдите снова. На X11 перезагрузите оболочку через `Alt+F2` → `r`.

**После обновления GNOME тема сбросилась.**
Крупные обновления GNOME часто сбрасывают тему Shell и отключают расширения. Включите User Themes заново и выберите Tailya.

**Часть элементов выглядит без стилей.**
В GNOME 47+ часть селекторов могла измениться, а некоторые могли появиться. Сообщите версию GNOME и приложите скриншот — или поправьте CSS под себя.

**Экран входа выглядит стандартно.**
Так и должно быть: GDM использует собственную тему и не загружает темы Shell из `~/.themes`.
